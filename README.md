# 🔍 بحث جهة التدريب

🌐 https://yzeeyd.github.io/training-entity-search/

أداة بسيطة تساعد طلاب الجامعة على البحث بسرعة داخل قائمة **جهات التدريب** بدل التمرير يدويًا بين مئات الجهات.

---

## ✨ الفكرة

قائمة جهات التدريب تحتوي على عدد كبير من الجهات، والبحث اليدوي بينها قد يكون مزعجًا.

الأداة تضيف واجهة بحث فوق صفحة الجامعة وتسمح للطالب بالبحث مثل:

- `بنك`
- `وزارة`
- `سدايا`
- `مستشفى`
- `تقنية`
- جزء من اسم الجهة

ثم يختار الطالب النتيجة، والأداة تختار الجهة مباشرة من القائمة الأصلية في الموقع.

---

## 🚀 المميزات

- 🔎 بحث سريع داخل جهات التدريب.
- 🇸🇦 دعم البحث باللغة العربية.
- البحث يتجاهل بعض اختلافات الكتابة مثل:
  - `ارامكو` / `أرامكو`
  - `بنك` / `مصرف`
- يتحمل بعض الأخطاء الإملائية البسيطة.
- إزالة الجهات المكررة من نتائج البحث.
- ⭐ إضافة الجهات إلى المفضلة.
- 🕘 عرض الجهات المستخدمة مؤخرًا.
- ترتيب النتائج حسب استخدام الطالب.
- تصنيفات سريعة:
  - بنوك
  - تقنية
  - حكومي
  - صحي
  - اتصالات
- نسخ اسم الجهة بضغطة واحدة.
- دعم لوحة المفاتيح:
  - `Enter` لاختيار أول نتيجة.
  - الأسهم للتنقل.
  - `Esc` لإغلاق الأداة.
- واجهة أبيض وأسود.
- Light / Dark Mode تلقائي.
- لا تحتاج Extension.
- لا تحتاج تسجيل دخول إضافي.
- لا يوجد Backend خاص بالأداة.

# 💻 التثبيت على الكمبيوتر

## Brave / Chrome / Edge

1. افتح:
   https://yzeeyd.github.io/training-entity-search/

2. أظهر شريط المفضلة باستخدام:

   `Ctrl + Shift + B`

3. اسحب زر:

   **🔍 بحث جهة التدريب**

   إلى شريط المفضلة.

4. افتح صفحة اختيار جهة التدريب في موقع الجامعة.

5. اضغط المفضلة:

   **بحث جهة التدريب**

6. ستظهر نافذة البحث.

# 📱 Android

على الجوال لا يمكن للموقع إضافة Bookmark تلقائيًا للمستخدم بسبب قيود المتصفح.

لذلك يتم التثبيت مرة واحدة يدويًا.

## الخطوات

1. افتح:
   https://yzeeyd.github.io/training-entity-search/

2. اضغط:

   **نسخ كود التثبيت**

3. أنشئ Bookmark جديد أو احفظ الصفحة في المفضلة.

4. عدّل الـBookmark.

5. اجعل الاسم:

   `بحث جهة التدريب`

6. استبدل عنوان الصفحة بالكود المنسوخ.

7. افتح صفحة التدريب في موقع الجامعة.

8. شغّل Bookmark:

   `بحث جهة التدريب`

---

# 📱 Samsung Internet

Samsung Internet لا يقبل وجود مسافات داخل عنوان الـBookmarklet.

لذلك يجب استخدام النسخة القصيرة بدون مسافات.

الكود:

```javascript
javascript:(()=>{s=document.createElement('script');s.src='https://yzeeyd.github.io/training-entity-search/app.js?t='+Date.now();s.onload=()=>window.TrainingEntitySearchV5?.open();document.documentElement.appendChild(s)})()
```

## التثبيت

1. احفظ أي صفحة في Bookmarks.
2. افتح **Edit bookmark**.
3. الاسم:

   `بحث جهة التدريب`

4. امسح Web address القديم بالكامل.
5. الصق الكود السابق.
6. اضغط Save.
7. افتح صفحة جهة التدريب.
8. شغّل الـBookmark.

# 🍎 iPhone / iPad

## الطريقة الأولى: Bookmarklet

1. افتح صفحة الأداة.
2. انسخ كود iPhone.
3. أضف الصفحة إلى Bookmarks في Safari.
4. افتح تعديل الـBookmark.
5. الاسم:

   `بحث جهة التدريب`

6. استبدل الرابط بالكود المنسوخ.
7. افتح صفحة التدريب.
8. افتح Bookmarks واختر:

   `بحث جهة التدريب`

---

## الطريقة الثانية: Apple Shortcuts

إذا لم يعمل الـBookmarklet على iPhone، يمكن استخدام تطبيق **Shortcuts**.

1. افتح تطبيق Shortcuts.
2. أنشئ Shortcut جديد.
3. أضف:

   `Run JavaScript on Webpage`

4. انسخ كود Apple Shortcuts من صفحة الأداة.
5. الصقه داخل الإجراء.
6. فعّل:

   `Show in Share Sheet`

7. افتح صفحة التدريب في Safari.
8. اضغط Share.
9. اختر الاختصار.

# 🔐 الخصوصية

الأداة لا تحتوي على Backend خاص بها.

ولا يتم إرسال:

- اسم الطالب
- الرقم الجامعي
- الجهة المختارة
- سجل الاستخدام

إلى أي خادم تابع للأداة.

المعلومات مثل:

- المفضلة
- آخر الجهات
- عدد الاستخدامات

`localStorage`

داخل متصفح المستخدم.

# ⚙️ كيف تعمل؟

الأداة لا تعدّل بيانات موقع الجامعة ولا تضيف جهات جديدة.

هي فقط:

1. تقرأ الخيارات الموجودة أصلًا في قائمة جهة التدريب.
2. تعرضها في واجهة بحث أسهل.
3. عند اختيار جهة، تضغط نفس الخيار الموجود في القائمة الأصلية.
